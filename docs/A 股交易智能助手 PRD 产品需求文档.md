# A 股交易智能助手 PRD 产品需求文档

> 版本：V1.0
> 目标：PC 网页端；核心能力 RAG、工具调用、MCP 上下文、Agent 主动智能；预留后续量化策略、回测扩展

## 1. 产品概述

### 1.1 产品背景

传统股票软件信息过载，数据繁杂，用户需要自己筛选信息、分析解读。本产品基于大模型 Agent 能力，实现**AI 主动复盘、AI 自动解读、AI 风险扫描**，把原始行情 / 财报 / 资讯，转化为大白话客观分析结论。

> 重要约束：**只做客观数据解读，不做投资建议、不荐股、不预测涨跌**，全程合规。

### 1.2 产品目标

1. PC 网页端，面向普通股票投资者；轻量化，无广告。
2. 四大核心 AI 能力：RAG 知识库、工具调用、MCP 会话上下文、Agent Loop 主动智能。
3. MVP 功能模块：市场热点复盘、个股智能分析、AI 智能问答、自选股风险监控。
4. 架构预留扩展：后续支持量化策略分析、策略回测功能。

### 1.3 用户角色

- 普通投资者：浏览市场行情、看个股基本面技术面、查询资讯、对自选股做风险监控、与 AI 对话提问。

### 1.4 非目标

- 不提供实盘交易。
- 不提供投资建议、不荐股、不预测股价涨跌。
- MVP 阶段不做量化回测，只预留扩展能力。

## 2. 核心能力说明

### 2.1 RAG 知识库引擎

私有知识库，用于减少大模型幻觉，保证金融专业度与合规输出。
知识库分为 5 类：

1. 财报规则库：财务指标释义、风险识别规则
2. 宏观政策库：宏观指标解读、政策传导逻辑
3. 市场规律库：市场、板块基础逻辑
4. 技术指标库：技术面基础释义
5. 合规风控库：约束输出，拦截违规话术

### 2.2 工具调用能力

Agent 可以自动调用外部工具获取实时数据：

- 行情查询工具：个股、板块价格、量价
- 财报数据工具：结构化财报指标、同比环比
- 热点资讯工具：新闻、公告聚合去重
- 板块资金工具：板块涨幅、资金流向
- 宏观数据工具：PMI、CPI、北向资金、汇率等

### 2.3 MCP 上下文管理

1. 跨页面会话记忆，保存当前浏览场景（市场 / 某只个股 / 某个板块）。
2. 用户从自选股跳转个股，再跳转 AI 问答，**自动携带标的上下文，用户无需重复输入股票代码**。
3. 保存多轮对话历史，支撑连贯问答。

### 2.4 Agent Loop 主动智能体

基于 LangGraph 实现有状态 Agent，支持定时触发、事件触发；信息不足自动多轮循环。

- 市场复盘 Agent：定时执行，生成首页市场全景复盘
- 个股分析 Agent：访问个股页触发，生成走势、财报、综合评价
- 问答 Agent：用户提问触发，多轮问答、自动调用工具
- 风险扫描 Agent：定时轮询用户自选股，自动识别财报 / 公告风险，打上风险标签

Agent 统一执行链路：
`任务输入 → 需求拆解 → 工具调用取数 → RAG知识增强 → 推理生成 → 合规校验 → 结果输出`

## 3. MVP 功能需求

### 3.1 市场热点复盘页（首页）

1. **AI 今日市场速览卡片**
   - Agent 定时生成（开盘、盘中、收盘更新）
   - 大白话总结市场情绪、主线板块、资金风格、市场强弱
   - 指标卡片：两市成交额、北向资金、涨跌家数、涨停家数
   - 展示数据更新时间
2. **热点新闻列表**
   - Tab 切换：当日热点 / 近 3 日热点
   - 每条新闻：时间 + 标题 + 标签【利好 / 利空 / 中性】+ AI 一句话解读
   - hover 展开查看原文 + 深度逻辑解读
   - 自动过滤无效重复资讯
3. **右侧边栏**
   - 热门行业板块 TOP10 列表
   - 宏观指标卡片：PMI、CPI、汇率、北向资金，附带 AI 简短解读

### 3.2 个股分析详情页

> MCP 自动锁定当前股票上下文，跳转 AI 问答自动带入该股票

1. **顶部行情头部**
   - 股票名称、代码、实时价格、涨跌幅高亮
   - 加自选按钮；今开、最高、最低、换手率
2. Tab 切换：走势分析 / 财报解读 / 综合评价

- **走势分析（默认）**
  - K 线图（5/10/20 日均线）
  - AI 技术面解读：趋势判断、支撑压力参考、量价总结（大白话）
- **财报解读**
  - 核心财务指标卡片网格：营收、净利润、扣非、毛利率、负债率、经营现金流（展示同比）
  - AI 输出：✅核心亮点（最多 3 条）；⚠️潜在风险（最多 2 条，风险标红）
- **综合评价**
  - 1‑5 星综合评分；分项：基本面、技术面、板块热度
  - 客观优势总结 + 潜在隐患总结

3. 右侧悬浮小卡片：常驻当前个股核心摘要，保留场景。

### 3.3 AI 智能问答页

1. 对话气泡界面：用户提问居右，AI 回答居左
2. AI 回答结构：数据结论 → 逻辑拆解 → 风险提示 → 合规免责声明
3. AI 加载态展示提示：`AI正在拆解问题、调取实时数据、推理分析`
4. 自动 MCP 上下文继承：如果用户之前浏览某只股票，提问默认带上该股票上下文
5. 违规提问自动拦截，输出标准化合规话术
6. 右侧快捷提问栏：市场复盘、热点板块、个股分析、指标解读、宏观查询，点击快速填充问题
7. 底部输入框支持多行输入。

### 3.4 自选股管理页

1. 功能：添加个股、批量管理自选股列表
2. 自选股表格：名称 / 代码 / 最新价 / 涨跌幅 / 走势状态 / 财报风险
3. **Agent 后台自动扫描每一只自选股**：检测业绩、现金流、减持、异动风险；风险列打【风险】红标；正常【正常】绿标
4. 点击条目跳转个股详情页，自动继承 MCP 上下文。

### 3.5 全局公共能力

1. 全站底部常驻合规声明：`股市有风险，投资需谨慎。本工具仅提供数据客观解读，不构成任何投资建议。`
2. 所有 AI 产出模块统一标识【AI 智能解读】，AI 输出末尾强制附带免责小字。
3. AI 加载状态透明可见，不黑屏无反馈。
4. 无广告、无弹窗推送。

## 4. 非功能需求

### 4.1 合规需求

1. 禁止输出荐股、买卖建议、股价预测、收益承诺。
2. 用户输入层做违规词拦截。
3. AI 输出层 RAG 合规库约束，强制追加免责声明。
4. AI 全部输出日志留存，可溯源审计。
5. 所有数据来源可溯源。

### 4.2 性能需求

1. 页面普通接口响应 < 500ms
2. AI 问答响应：首字返回 < 3‑5s（依赖大模型 API）
3. Agent 定时任务错开高峰，避免数据源压力。

### 4.3 兼容性

PC 网页端，支持 Chrome、Edge 主流浏览器。

## 5. 后续扩展需求（暂不 MVP 实现，架构预留）

1. 量化策略分析模块
2. 策略回测引擎：支持自定义策略、回测、滑点手续费模拟、绩效指标
3. 策略优化 Agent：基于回测结果 AI 诊断、参数调优、风险解读
4. 多模态增强：解析 K 线图表、财报表格图片

## 6. MVP 版本迭代计划

1. 阶段 1：基础页面、数据源对接、基础工具调用
2. 阶段 2：RAG 知识库、问答 Agent、MCP 上下文、合规校验
3. 阶段 3：市场复盘 Agent、风险扫描 Agent；首页、自选股 AI 能力落地
4. 阶段 4：全量联调、合规测试、性能优化，上线
