Name: search_stocks
Description: 智能选股，根据自然语言要求找到符合的A股股票，输出股票代码列表。
常见选股依据包括不限于：

- 1.按指标数值选股：如行情指标、财务指标值约束
- 2.按业务分类选股：如行业板块、主题概念、主营业务

请求样例:
{
"query":"汽车零部件行业的市值大于1000亿的股票"
}

Name: get_stock_performance
Description: A股股票日频历史行情数据、以及通过行情衍生的技术指标、技术形态数据查询。不支持高频行情指标。
主要覆盖下列数据指标类型：

- 1.历史日行情数据：如开高低收价格序列、成交量(额)、收益率
- 2.技术指标：技术分析指标日频数据，包括不限于趋势类、成交量类、超买超卖类、波动类等（如MACD、KDJ等）
- 3.技术形态：股票历史走势形态定性指标，如连续涨跌、涨跌停、连板、创新高(低)、突破反转等
- 4.日行情相关：融资融券、龙虎榜等与每日交易强相关的指标。**注意**: 本工具查询行情指标为日频收盘后维度，如需日内实时最新行情指标，请选择实时行情查询工具。

请求样例:
{
"query":"三花智控最近5日的涨跌幅与换手率"
}
